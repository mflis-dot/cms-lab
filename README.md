# KompSerwis - Serwis komputerowy w Poznaniu

## 1. Opis projektu

Projekt strony internetowej stworzonej w oparciu o WordPress, przeznaczonej dla fikcyjnej firmy świadczącej usługi diagnostyki i naprawy sprzętu komputerowego na terenie Poznania i okolic.

## 2. Oferta

Firma KompSerwis specjalizuje się w diagnozowaniu i usuwaniu usterek sprzętowych oraz programowych następujących urządzeń:

- Komputery stacjonarne
- Laptopy i notebooki
- Drukarki
- Konsole do gier

## 3. Grupa docelowa

Główną grupą docelową są osoby prywatne oraz właściciele małych firm z Poznania i okolic, którzy potrzebują profesjonalnej pomocy w przypadku awarii sprzętu komputerowego lub problemów z oprogramowaniem.

### Persona 1 - Anna, osoba prywatna

**Profil:** 29 lat, pracownik biurowy, mieszka w Poznaniu.

| Kryterium | Charakterystyka |
| --- | --- |
| Cel | Szybka naprawa laptopa potrzebnego do pracy i codziennego użytkowania. |
| Problem | Laptop działa bardzo wolno, przegrzewa się i niespodziewanie wyłącza się podczas pracy. |
| Urządzenie | Laptop z systemem Windows. |
| Potrzeby | Szybka diagnoza, jasna informacja o kosztach i terminie naprawy. |
| Oczekiwana akcja (CTA) | „Zgłoś naprawę” lub „Zadzwoń do serwisu”. |

### Persona 2 - Michał, właściciel małej firmy

**Profil:** 41 lat, przedsiębiorca prowadzący niewielkie biuro w okolicach Poznania.

| Kryterium | Charakterystyka |
| --- | --- |
| Cel | Zapewnienie sprawności sprzętu komputerowego wykorzystywanego w firmie. |
| Problem | Drukarka przestała druklować, a komputer pracownika zgłasza błędy systemowe. |
| Urządzenie | Komputer stacjonarny i drukarka laserowa. |
| Potrzeby | Profesjonalna diagnoza, sprawna obsługa i możliwość uzyskania wyceny. |
| Oczekiwana akcja (CTA) | „Poproś o wycenę” lub „Skontaktuj się z nami”. |

## 5. Wybór systemu CMS - WordPress

Do realizacji projektu wybrano system WordPress zamiast Wix, Shopify lub Drupal.

Uzasadnienie wyboru:

1. Według danych W3Techs z 14 listopada 2026 roku WordPress obsługuje 38,7% wszystkich stron internetowych i posiada 57,6% udziału w rynku systemów CMS, co potwierdza jego dużą popularność i rozwinięty ekosystem.
2. W przeciwieństwie do Shopify, które koncentruje się przede wszystkim na handlu elektronicznym, WordPress zapewnia elastyczne narzędzia do tworzenia strony usługowej, zarządzania treścią, rozbudowy formularzy kontaktowych i optymalizacji SEO bez konieczności budowania sklepu internetowego.
3. W porównaniu z Wix i Drupal WordPress stanowi odpowiedni kompromis między łatwością obsługi, możliwościami rozbudowy i kosztami utrzymania, dzięki czemu odpowiada potrzebom lokalnego serwisu KompSerwis, który chce samodzielnie aktualizować ofertę i pozyskiwać klientów.
